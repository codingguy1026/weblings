# Drawing Chat · Classic UI Prototype

Weblings 저장소 안에 독립적으로 추가된 **Drawing Chat**의 브라우저용 정적 UI 시제품입니다. 기존 Weblings Discord 봇 코드는 변경하지 않았습니다.

## 열어보기

`drawing-chat/index.html` 파일을 내려받아 웹 브라우저로 열면 됩니다. 별도 의존성이나 빌드 과정은 없습니다. 정적 웹 호스팅을 사용한다면 이 폴더를 공개 디렉터리로 배포할 수 있습니다.

## 데모에서 가능한 동작

- 2025년 개편 이전 카카오톡에서 영감을 받은 **친구 / 채팅 / Station / 더보기** 메뉴 분리
- 가상의 친구를 선택하여 1:1 채팅 화면 보기
- Enter 전송, Shift+Enter 줄바꿈, 로컬 저장소에 데모 메시지 저장
- Station 참여 후 데모 채널에 메시지 작성
- 라이트 / 다크 테마 전환
- 모바일 하단 탭 및 대화 화면 전환
- 검색, 데모 메시지 초기화

## 개발 전제 및 주의사항

**실제 메신저 서비스가 아닙니다.** Drawing ID 로그인, 실시간 서버 통신, 사용자 동기화, 그룹 채팅, 신고, 알림, 채팅 권한, 암호화, 파일 업로드는 구현되지 않았습니다. 모든 친구와 채널 및 초기 메시지는 가상 데이터입니다. 대화 입력은 현재 기기의 브라우저 로컬 저장소에만 저장되므로 개인 정보나 비밀을 입력하지 마세요.

서비스화할 때에는 현재 Drawing ID 인증 방식부터 확인하고, 서버 기반 인증/권한과 채팅 데이터 모델 및 보안 검증을 구현해야 합니다. UI는 메신저 중심으로 유지하고 Station은 별도 공간으로 제공하는 것을 기본 원칙으로 합니다.
