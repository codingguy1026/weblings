# Drawing Chat · 예전 정적 HTML 시안

**현재 주 프로젝트는 저장소 최상단의 Next.js 앱입니다.**

이 폴더의 `index.html`은 이전에 제작했던 **정적 HTML/CSS/JavaScript 원형 시안**을 참고용으로 보관한 것입니다. 새로운 화면은 `../app/`, `../components/`, `../lib/`에서 개발합니다.

## 실행하기 (Next.js 앱)

Codespaces에서 어느 위치에 있든 다음을 실행할 수 있습니다.

```bash
cd /workspaces/weblings
git pull
npm install
npm run dev
```

또는 이 폴더 안에서 `npm run dev`를 사용하면 상위 Next.js 앱을 실행합니다. **5173 포트**를 열면 됩니다.

> 아직 실제 메신저가 아닌 UI 데모입니다. 가상의 친구/채팅/Station을 표시하고 사용자의 입력은 브라우저 로컬 저장소에만 기록됩니다. Drawing ID 로그인 및 실시간 서버 통신은 추후 작업입니다.
